# tampermonkey-scripts

個人用 Tampermonkey userscript 集。

## Scripts

### google-drive-copy-path.user.js
Google Drive の現在のフォルダー、または選択中ファイルのフルパスをクリップボードへコピーする。

### gmail-copy-mail.user.js
Gmail のメール内容をコピーする。

### outlook-copy-mail.user.js
Outlook.com のメール内容をコピーする。

### gmail-create-outlook-event.user.js
Gmail のメール本文で選択した日時から Outlook の予定作成画面を開く。

### outlook-create-event.user.js
Outlook.com のメール本文で選択した日時から予定作成画面を開く。
